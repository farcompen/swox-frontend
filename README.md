# SWOLX Web Monitor

React + Vite kontrol paneli. Varsayılan backend: https://swolx-mobile.vercel.app

## Local
npm install
npm run dev

## Vercel
Framework Preset: Vite
Build Command: npm run build
Output Directory: dist

İstersen Vercel Environment Variables içine:
VITE_API_BASE_URL=https://swolx-mobile.vercel.app
